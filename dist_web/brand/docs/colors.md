# Paleta de Colores — Universidad Autónoma
Manual de Marca 2026

---

## Sistema de color

La marca opera con tres paletas independientes según la línea académica.
El **Naranja Autónoma** es el color madre compartido por los tres sistemas.

## Variables CSS

```css

--ua-naranja:        #FF6600;
--ua-amarillo:       #FFE357;
--ua-morado-claro:   #CBC7FF;
--ua-celeste:        #92E8FF;
--ua-verde-claro:    #BAF597;

/* Posgrado */

--ua-marron-oscuro:  #1A0901;

/* Educación Continua */

/* Neutros */
--ua-blanco:         #FFFFFF;
--ua-negro:          #000000;
```

---

## Reglas de uso

- El naranja `#FF6600` es el **único color compartido** entre los tres sistemas.
- No combinar colores de sistemas distintos en una misma pieza.
- Respetar los porcentajes de uso para mantener el look & feel de cada línea.
- Solo utilizar las combinaciones aprobadas (ver `color-combinations.md`).
