## Trama (patrón de isotipo)

Recurso decorativo para merch, banderolas, totebags, uniformes, etc.

| Tipo de combinación          | Ejemplos                                      |
|------------------------------|-----------------------------------------------|
| Naranja sólido               | Isotipo naranja sobre naranja (relieve)       |
| Naranja + color secundario   | Naranja/verde, naranja/celeste, etc.          |
| Entre colores secundarios    | Morado/celeste, celeste/amarillo, etc.        |
| Color secundario + blanco    | Verde/blanco, celeste/blanco, amarillo/blanco |

## Símbolo como recurso gráfico sobre fotografía

| Sistema           | Color del símbolo |
|-------------------|-------------------|
| Pregrado          | Naranja           |
| Posgrado          | Camel             |
| Educación Continua| Morado Intenso    |

**Posición**: a la altura de la cabeza de la persona.
**Tamaño**: mínimo = altura del rostro · máximo = ligeramente más grande que el rostro.
